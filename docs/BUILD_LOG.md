# Build & verification log

## 15 Nov 2026

- **Model routing & deprecation audit.** Queried the Gemini `/v1beta/models` endpoint to confirm active model IDs. Defaults moved from `gemini-2.5-flash-lite` / `gemini-2.5-flash` (on Google's deprecation list) to `gemini-3.5-flash-lite` (fast tier) and `gemini-3.8-flash` (deep tier) in `config.py`, `.env.example`, `DEPLOY.md` and `ARCHITECTURE.md`. Added `load_dotenv()` in `config.py` so local Uvicorn runs read `.env` automatically.
- **First live data refresh.** Ran `python -m scripts.refresh --export` against Yahoo Finance (2,286 end-of-day price rows), NSE corporate announcements (34 filings) and screener.in (22/22 fundamentals pages). The committed snapshot is this run.
- **Classification: measured, then fixed.** The first live run classified 21 of 34 filings (62%) by rules, and reading the misses showed material items in the routine pile: Kaynes' actual quarterly results, an HDFC Bank director change, an L&T order win, a Kaynes M&A term sheet and a Bajaj Finance preferential allotment. Causes: the "Analysts/Institutional Investor Meet/Con. Call" subject matched the earnings-call rule before the investor-meetings rule; the classifier ignored the rules' text-condition column; and a few standard NSE subjects weren't covered. After the fix: 30 of 34 (88%) with no model call, and only the 4 genuinely ambiguous filings go to the fast model. Each case is a regression test using NSE's verbatim text. `python -m scripts.refresh --reclassify` re-labels the snapshot without refetching.
- **Results card showed the wrong quarter.** Kaynes filed Sep-2026 results while screener's table still ended at Jun 2026, and the card showed June's numbers under the September filing. The PDF fallback described in `results.py` had never been wired in. The card now matches the filing's stated period, and otherwise uses PDF extraction (with a key) or says the quarter isn't tabulated yet.
- **Alerts read only the last session.** Price/volume alerts now cover every session in the window you pick, with the date shown, and say which thresholds are active when nothing triggers.
- **Deploy blocker: snapshot encoding.** On Windows, `write_text()` saved `fundamentals.json` as cp1252, which the Linux container would fail to decode at boot. All file I/O now states UTF-8; tests check the committed data and the code.
- **LLM health check.** `/api/meta` reports `llm.enabled: true` and `failures: 0`.
- **Persona & repo clean-up.** Renamed the mock investor in `portfolio.json` to `Demo_Investor` and removed private prep notes from the public repo.
- **Stale-date fix.** `TODAY` in `network/graph.py` and `NOW` in `demo.py` were fixed at server start, so on a long-running server "last spoke X ago" and warmth scores froze at the boot date. Both are now evaluated per call.
- **Docs repaired.** `DEPLOY.md` and `ARCHITECTURE.md` had been truncated and over-escaped by a Markdown editor; restored from the original and re-applied the edits above.
- **Deploy guards.** Added `python-dotenv` (imported but undeclared), an unauthenticated `/api/health` for Render's probe, tests for the access gate and for undeclared imports, and CI that runs the suite on a clean install, then boots the Docker image with the gate on.
- **Grounding guards on model output.** Guidance targets returned by the model must appear in the quoted sentence; bull/bear points must cite real facts, and every number in them must appear in those facts. Previously the prompt asked for this but nothing checked it.
- **Keyword fallback for guidance tightened on real transcripts.** On ASIANPAINT and DIXON with no model, the extractor took analyst questions ("You have guided…", "Just to understand…"), past results ("growth has been strong at 11.2%") and capacity-utilisation figures as management targets, and graded volume and quarter-on-quarter targets against annual revenue. Each case is now a test using the verbatim sentence. ASIANPAINT went from 9 items (7 "delivered") to 4 honest ones, and a no-model verdict is labelled "rough read".
- **LLM router hardening.** One backed-off retry on 429/5xx; a malformed JSON reply is no longer cached (it would have been replayed forever); filing and transcript text is fenced as data in every prompt; `/api/meta` reports calls by tier, retries and unparseable replies.
- **Evaluation harness.** `eval/filings_dev.jsonl` (34 live filings) plus `scripts/eval_classify.py`: 88% coverage, 30/30 rule precision, 0 material filings lost by rules. CI enforces the floor.
- **Polish pass (see `IMPROVEMENT_LOG.md`).** Pinned dependencies; hardened the access gate (constant-time check, key removed from the URL, `no-store` on personal data); capped and validated network imports; validated NSE symbols before outbound fetches; `utcnow` deprecation; step-by-step loading text for first-look research; PAT margin no longer graded as EBITDA margin (found on TATAPOWER); a frontend syntax check in CI, added after a JS regression this pass introduced and caught in the browser; installable app icons; a two-minute reviewer tour.
- **Model accuracy on the ambiguous residue, measured.** With the live key, the 4 filings rules can't settle scored 1/4 and lost a material fund-raise: the prompt gave bare labels with no definitions, and its system message made "unclassified" the safe answer. With the reference doc's definitions and an explicit cost asymmetry: 2/4 exact and 0 material lost, with the remaining errors over-surfacing. Domain hints written after seeing the misses reach 4/4, but that is tuning on the test set, so the claim stays at the second figure. The model path itself is verified: 0 call failures on `gemini-3.5-flash-lite`.
- **Live cards verified with the model on; two crashes fixed.** Management-change bios now read the filing's attachment, where SEBI's brief profile lives (HDFC Bank's card went from empty to a full career with 2 network paths). The results PDF fallback scanned only the cover pages (the statement was on page 7 of 25) and its cache handed back a truncated copy; it now selects statement pages, keeps only figures printed in them, converts ₹ million to crore (the card had been 10x too high), and cross-checks the previous quarter against screener: Kaynes revenue matches (946 vs 946 cr) and PBT/PAT differences are shown on the card. With the model on, string-typed numbers crashed the Brief and a bare-list reply crashed research for every company; both now parse defensively in one place, with tests.
- **Promised-vs-delivered verified on live DIXON with the model.** ₹ targets had been graded as growth percentages and segment targets against company totals; both are now "needs judgement". The facts pack no longer feeds "not checkable" notes into bull/bear. The deep tier failed 4 of 4 calls (a 503, then timeouts), so it now times out at 25 s and falls back to the fast tier (`deep_fallbacks` in `/api/meta`).
- **Held-out evaluation.** 199 filings from the three prior weeks, labelled blind: 84% rule precision and 27 material filings lost as built (the honest generalisation number); 97% and 9 after fixing the rules, now a second CI floor. Labelling it exposed a dev-set label copied from rule output; corrected. Two retries on rate limits removed the 5 failures seen in a 47-call burst.
- **Voice.** The Brief can be read aloud (ranked order, demo items flagged, who to call; built from the cards so it never says anything the screen doesn't) and Ask takes a spoken question where the browser supports speech recognition. Both use the browser's speech APIs: no server cost. The read-out was verified in the browser; the microphone is blocked in the preview pane, so voice input is untested until it runs on a phone.
